# Soban Tales Blender와 VFX 제작 판단

## 이 문서의 성격

사용자 제공 FORESIGHT 제작 자료의 실패·수정 사례를 Soban Tales에 맞춰 정제한 제작 가이드다. FORESIGHT 소스·미디어·리그를 가져온 것이 아니며 Blender 장면이나 검증기의 구현 완료를 의미하지 않는다. 제품 사실은 soban-tales.md를 따른다. Blender 버전·렌더 엔진·실제 장면과 의존성을 확인한 뒤 구체적인 설정을 선택한다.

## 작업을 맡길 도구

| 문제 | 우선 경로 | 전달할 입력 / 확인할 결과 |
|---|---|---|
| 인물과 기물의 위치·잡기·들기·놓기 | Blender의 리그·제약·IK와 수작업 보정 | 실제 모델 ID, 그립 프레임, 지지면, 전체 몸의 하중 / 손뿐 아니라 발·골반·소품 확인 |
| 걷기·회전·춤의 기본 동작 | 현재 사용 가능한 Kimodo 등 모션 소스 → Blender | 원본 스켈레톤·리타깃 매핑·경로·속도 / 발 접지와 경계 보행 위상 재검사 |
| 소매·치마의 후행·충돌 | Blender 의상 제어·필요한 구간의 시뮬레이션 | 신체·기물 콜라이더, 시뮬레이션 시작, 캐시 범위 / 관통·떨림·렌더 일치 |

| 홍보용 모션·티저·편집·음향 | video-shotcraft/Remotion 또는 기존 편집 도구 | 광고 전용 콘티·승인 자산·음원 / 투사 마스터와 분리 |
| 현장 투사 | 실제 출력·워핑·마스킹·수동 큐 시스템 | 장비/상판/식기 실측 / 네 좌석·서빙·주변광 리허설 |

도구를 바꿀 이유는 해결할 문제와 관찰 결과로 설명한다. 특정 도구가 연결됐거나 설치됐다는 사실만으로 접촉·의상·현장 적합성이 해결되었다고 하지 않는다.

## 기준본과 수정 범위

작업 시작 시 사용자가 선택한 기준본의 경로·해시·버전, 수정 시간/프레임, 보존 장면·동작·음원·캐릭터를 기록한다. 최근 수정시각이나 final 파일명으로 기준본을 바꾸지 않는다. 기존 120초 검토본과 최신 수정 본편을 별도 계열로 관리한다.

동작 수정이면 화면 크롭으로 손 관통을 숨기지 않는다. 광고 비율 변경이면 작은 MP4를 확대하는 대신 원래 Blender/Remotion 장면에서 해당 카메라·출력 크기로 다시 렌더한다. 단순 전달 포맷 변환에는 불필요한 FPS·길이 변경을 넣지 않는다. 투사용은 카메라 재프레이밍으로 고정 식탁 좌표를 움직이지 않는다.

## 장면과 시간 구조

- 초와 프레임을 모두 기록하고 FPS를 해당 run에 고정한다. 24fps 편집본과 30fps 검토본의 프레임 번호를 그대로 공유하지 않는다.
- 인물·소품·음식·배경·정확한 그래픽·음향을 관리 가능한 계층으로 나눈다. 부모 변환과 로컬 좌표를 확인한다. 원점/스케일 수정이 이미 맞춘 손·발·기물 배치를 깨지 않는지 확인한다.
- 전환 전·중·후의 접시·바닥·기물 지지면과 가림을 비교한다. 조명이나 블룸으로 기하 오류를 숨기지 않는다.
- 캐릭터 모델과 음식·기물을 바꾸지 않고 짧은 대표 상호작용을 먼저 평가한다. 막내 체급·항아리 무게·공동 젓기의 손 바꿈이 한 구간 안에서 연결되어야 한다.

## 캐시와 연속 렌더 검토

원 자료의 WebGL shader 상태 사례에서 가져온 교훈은 '단독 장면 통과를 전체 재생 통과로 간주하지 않기'다. Blender가 동일한 결함을 갖는다고 단정하지 않는다.

의상·물리 등 이력 의존 구간은 현재 시뮬레이션 방식에 맞게 초기 상태부터 평가하거나 유효한 bake/cache를 사용한다. bake 전에 .blend 저장, 캐시 시작/종료와 경로, 외부 캐시 의존성을 기록한다. 설정·메시·충돌체가 변경되면 해당 캐시의 유효성을 다시 확인한다. 정확한 갱신 방식은 사용 중인 Blender 버전과 시뮬레이션별 문서를 따른다.

검토 구간은 단독 테스트 외에 앞 동작을 거친 진입·동작·종료를 포함한다. 직접 특정 프레임으로 이동한 결과, 순차 재생 결과, 실제 렌더 프레임을 대조한다. 같은 프레임의 불일치는 의존성·캐시·시간 평가·렌더 설정을 조사하는 단서다. 모든 차이를 캐시 탓으로 돌리지 않는다.

공식 근거: [Blender 물리 bake/cache](https://docs.blender.org/manual/en/3.6/physics/baking.html). 링크는 3.6 문서의 일반 원리이며 설치 버전의 메뉴/API를 확인한 안내는 아니다.

## 합성과 투사

배경/바닥·인물/기물·효과·좌석 글자를 분리할 때 공통 좌표·색 관리·알파 처리·접촉 그림자·가림 순서를 명시한다. 서로 다른 시점으로 만든 레이어는 합친 결과에서 다시 검사한다. 레이어 분리가 접촉을 자동 보존하지 않는다.

한 접시에서 승인한 동작을 네 자리로 확장할 때 단순 복제로 끝내지 않는다. 상/하 인사·좌석별 읽힘·그림자 방향·서비스 공간을 확인한다. 공유 2무대와 전체 1무대는 별도 배치다. 부채 전환은 투사 표면을 가리는지, 광고 카메라를 가리는지 구분한다.

7:4 마스터의 실제 출력 회전·장비 해상도·워핑·마스킹은 현장 입력에 따른다. 높은 해상도 저장은 선명도나 정렬의 합격 증거가 아니다.

## 타락죽에 적용할 첫 작업

1. 승인 대상으로 삼을 인물·항아리·그릇·의상 버전과 기준본을 지정한다. 길이는 전체 120초를 강제하기 전에 사건이 완결되는 시험 구간으로 정한다.
2. 접근 → 잡기 → 하중 이동 → 기울이기 → 흐름 시작/정지 → 지지면에 놓기 → 손 철수의 프레임과 원인을 작성한다.
3. 항아리 입구·우유 흐름·손 그립·발/골반 지지·소매 접촉을 동시에 볼 수 있는 진단 뷰와 최종 투사 뷰를 마련한다.
4. 정상 속도에서 의도·시선·준비·반응·여운을 보고, 문제 구간을 프레임 단위로 추적한다. 궤적 수치 통과만으로 연기를 승인하지 않는다.
5. 앞 장면을 거친 재생·렌더를 확인한 뒤 네 자리 합성과 대기/서빙 연결로 확장한다. 전체 본편 완료 상태를 앞당겨 기록하지 않는다.
