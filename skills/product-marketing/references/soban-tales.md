## Product overview

Soban Tales는 작은 사람들이 실제 식탁과 접시 위에서 한국 음식을 만드는 이야기를 보여주고, 그 사건을 실제 코스 요리의 서빙으로 연결하는 자체 IP 테이블 프로젝션 다이닝이다. 영상·캐릭터·세계관·재사용 3D 자산·공연·식사 루프·운영 큐가 하나의 경험이다. SaaS나 영상 생성 서비스로 설명하지 않는다.

상위 IP는 Soban Tales, 첫 챕터는 기존 SURA·수라상 자산을 기반으로 한 궁중의 하루다. 「오늘 하루, 당신이 왕이다」는 원안 주제다. Le Petit Chef는 경험 형식의 참고이며 제휴·라이선스 관계는 확인되지 않았다. 장면·인물·음악을 복제하지 않는다. 엄밀한 특정 시대 재현이 아니라 한국 궁중 생활과 음식에서 영감을 받은 창작 다이닝이다.

## Audience and positioning

손님에게는 네 사람이 음식과 작은 인물의 관계를 함께 경험하는 식사다. 한국 음식·이야기·공예적 질감과 몸짓 유머가 제품 차별점이다. 음식과 대화를 방해하는 효과 경쟁을 피한다.

검증할 사업 경로는 직영·팝업 체험, 호텔·레스토랑 협업, 콘텐츠·설치·운영 패키지다. 이는 후보이며 계약·오픈·판매·확정 고객군을 의미하지 않는다. 실제 구매자, 지역, 일정, 가격, 좌석 수 확장, 수익모델과 제휴 조건은 미확정이다. 고객 인용·만족도·ROI·매출을 만들지 않는다.

## Current status and evidence

- 개발·검토 단계. 전체 5코스 공연과 현장 투사의 최종 검증이 남아 있다.
- 설명서상 11종 인물 자산 목록은 존재하지만 전 인물·동작 제작 승인이 아니다. 초기 5종 Tripo 리그·4K 텍스처와 손가락·얼굴·발 IK·그립의 완성은 구분한다.
- 기존 타락죽 v12 검토 영상: 설명서상 H.264, 1280×720, 30fps, 3,600프레임, 120초, 오디오 없음. 직접 파일을 다시 검사한 값은 아니다.
- 후속 편집본은 24fps·2,880프레임과 외부 치마 캐시를 사용하는 별도 자료다. 두 버전의 사양을 섞지 않는다.
- 설명서가 읽은 film_state.json 리비전 868: 최신 수정 전체 본편 없음, 전체 렌더 시작 전. 이 리비전이 지금도 최신이라고 단정하지 않는다.
- 우유는 곡선 메시, 죽은 표현용 표면 애니메이션인 검토본이 있다. 전체 유체 시뮬레이션으로 홍보하지 않는다.
- 아카이브 67,042개 파일·약 209.91GB 등의 수치는 10월 20일 특정 보관본 집계다. 고유 자산 수·완성 분량·현재 전체 실측으로 바꾸지 않는다. 같은 디스크의 복사본은 외부 백업이 아니다.

## Characters and visual identity

세 나인: 작은 막내, 중심을 잡는 조리 담당, 흐름을 정리하는 선배. 키·실루엣·반응 속도·습관·관계로 구분하며 개별 이름과 최종 설정은 미확정이다. 기미상궁은 별도 종지·은수저로 시식한다. 무희·악사·보조 인물·음식 나르는 나인은 역할·소품 그립이 달라야 한다.

정교하게 모델링한 작은 사람, 사실적인 한복 천·도자기 유약·돌·음식의 윤기와 수분, 귀여움과 몸짓 유머를 지향한다. 청남색 나무·절제된 금빛 문양·따뜻한 등불·차가운 주변색은 탐색 방향이며 모든 화면의 최종 승인은 아니다. 실사 인형·카툰·저해상도 3D를 임의 혼합하지 않는다.

캐릭터 다각도 이미지·3D 모델·생성 엔티티를 같은 asset ID로 대응시킨다. @Element를 글로 적는 것과 실제 슬롯 연결을 구분한다. 얼굴·UV·텍스처·승인 디자인 원본을 덮어쓰지 않는다. 기물·음식은 독립 자산으로 소유자와 시작·종료 위치를 기록한다.

## Projection versus promotion

- 투사 기준: 1400×800mm, 7:4. 두께 32mm·높이 750mm·좌석은 제작 가정으로 현장 실측이 아니다. 최종 회전·워핑·마스크·해상도는 설치 확인 후 결정한다.
- 개인 4무대 → 공유 2무대 → 전체 1무대. 구절판 공유 무대는 두 접시 사이에 4명씩, 총 8명. 검은 칸막이로 나누거나 중앙에 모두 모으지 않는다.
- 투사 마스터의 접시·바닥·좌석 좌표는 고정한다. 접시를 타원으로 왜곡하거나 이동 카메라로 분위기를 해결하지 않는다. 캐릭터 가독성은 별도 조절하고 접촉·가림을 재검사한다.
- 각도는 바닥 기준 고도각인지 수직 기준 기울기인지 명시한다. 바닥 기준 75도는 탑뷰 90도에 가깝다. 네 좌석에 동시에 정확한 하나의 입체 원근 착시를 보장하지 않는다.
- 상·하 손님을 향한 인사·글자·광원·그림자는 좌석 좌표로 설계한다. 메인에서 모든 손님이 전골과 갈비를 함께 경험하도록 실제 배치를 먼저 정한다.
- 광고는 별도 콘티·출력이다. 카메라 이동·손님 시점·한복 렌즈 가림·매치 컷은 광고에서 사용할 수 있다. 요청된 한복 전환을 부채 전환으로 임의 교체하지 않는다.
- Remotion은 광고·타이틀·정확한 2D 합성·프리뷰에 적합하다. 3D 접촉·천·음식 물리나 현장 보정을 자동 해결하는 도구로 제시하지 않는다.

## Performance and production

기획 → 초 단위 콘티 → 일관된 기준 이미지 → 필요한 러프 프리비즈 → 사용자 확인 → 선택한 제작 방식 → 합성 → 검토. 제품 문서의 확인 지점과 사용자가 현재 명시한 권한을 함께 따른다. 프롬프트를 반복하기 전에 사건·참조·동선을 점검한다.

Blender는 정밀 3D·리그·IK·접촉·렌더, Tripo는 초기 자산·리그, Kimodo는 전신 기본 동작, Higgsfield는 선택한 생성 모델 후보, SURA Studio는 로컬 배치·경로·동작·접촉 편집 역할이다. Unreal 이전은 필수가 아니다. 실제 설치·연결 상태와 도구별 비용은 별도 확인한다.

모든 액션에 의도·시선·준비·하중·반응·여운을 설계한다. 소품 놓기: 접근 → 지지면 접촉 → 하중 전달 → 손 놓기 → 손 철수. 손만 고정하지 말고 발·무릎·골반·몸통·기물·의상을 함께 확인한다. 구간 경계의 위치·속도·보행 위상을 확인한다.

부채바람은 출발 용기 → 부채 방향 → 소매·띠·재료 반응 → 목표 접시 착지로 이어진다. 전환은 가릴 면·완전 가림 프레임·가림 중 변화·재등장 상태를 명시한다. 기하학 원·테두리·글자·웰컴은 정확한 로컬 합성을 우선한다.

타락죽: 0–20초 아침, 20–45초 흑미 맷돌, 45–75초 불·우유, 75–95초 공동 젓기, 95–105초 마무리(최신안 고명 없음), 105–120초 상궁 별도 시식. 흰 우유+흑미의 회보랏빛·입자·점성을 유지한다.

## Service and acceptance

장소 전환 → 본 공연 → 준비 대기 → 수동 서빙 큐 → 직원 설명 → 식사 루프 → 퇴식 확인 → 다음 코스. 뜨거운 음식 서빙과 다음 코스를 자동 타이머로 강행하지 않는다. 메인은 마지막 그릇이 놓이고 직원 손이 빠진 뒤 수동 큐로 음악 종지·등불을 실행한다.

공연·서빙·식사별 음식 제외 마스크와 안전 화면을 구분한다. 강한 청색·녹색 투사로 음식 색을 바꾸지 않는다. 현장 상판·주변광·그림자·음향·접시 위치·준비 지연·중복 클릭·재시작을 실측·리허설한다.

완료 판정은 세 축이다: 파일/디코딩/길이/오디오 등 기술 성공, 정상 속도와 오류 구간의 연기·접촉 품질, 네 좌석의 현장 투사·서비스 적합성. 테스트 수·한 구간 통과·4K 저장을 전체 공연 승인으로 확대하지 않는다.

다음 우선순위: 브랜드·인물·메뉴 기준 확정 → 타락죽 완전 상호작용 한 구간 승인 → 120초·4자리 합성 → 구절판·경회루 확장 → 전 코스 90분 리허설 → 현장 보정·납품.

납품 범위 후보: 코스별 공연, 안내·전환·엔딩, 대기·식사 루프, 웰컴 원본, 마스크, 분리 음향·큐시트·재생 설정, 편집 씬·자산·버전 기록. 광고는 별도 산출물.

## Brand voice and commercial boundaries

따뜻하고 구체적인 한국어를 기본으로 작은 몸짓·음식·관계가 보이도록 설명한다. 과장된 기술 자랑, 이미 상용 운영 중이라는 표현, 검증되지 않은 역사·권리·성과 주장을 피한다. 공개 카피에는 현재 단계와 보여주는 버전을 정확히 밝힌다.

가격·판매·티켓·예약·제휴·유료 광고·발송·외부 생성은 각각 현재 요청의 범위와 필요한 입력에 따라 진행한다. 개발 중이라는 이유만으로 무관한 작업을 중단하지 않되 미확정 사항은 제안/가설로 표시한다. 이 저장소는 제작 시스템이나 예약 플랫폼이 아니다.

## Paid Ads and Learnings

집행 예산·캠페인·성과는 미확정. 광고 성과와 공연 품질을 혼동하지 않는다. 파일럿에서는 이야기 이해도, 음식·대화 방해, 큐 안정성, 좌석별 가독성, 테이블당 설치·제작·업데이트 비용을 측정한다. 측정 전 수치는 목표 또는 가설로 표시한다.
