# 근거에서 다음 콘텐츠로

이 스킬은 사람이 판단하는 마케팅·제작 루프를 지원한다. 실행 주기와 다음 검토일을 정하되 이 스킬 호출만으로 예약 실행·광고 집행·게시·메시지 발송을 설치하지 않는다.

먼저 현재 제품 맥락과 [협업·시점·인계 기준](references/operating-contract.md)을 읽는다. [빈 사이클 기록](assets/cycle.example.json)을 복사해 실제 근거만 채운다. 하나의 국가·대상·목표·콘텐츠 ID·변형·버전을 사용한다. 실제 데이터 없이 분석 완료라고 쓰지 않는다.

1. **관찰**: 준은 GA/키워드 성과, 유사 콘텐츠, 고객 반응을 모으고 제작자가 최신 자산 상태를 제공한다. 각 소스의 확인일과 데이터 반영 시점은 다르다. 한 소스가 없다고 다른 조사를 중단하지 않는다.
2. **가설**: 관찰 사실·해석·반증 가능성을 구분해 바꿀 요소 하나를 제안한다. 레퍼런스가 유행해도 제품의 약속을 입증하지 못하면 탈락시킨다.
3. **협업**: 미아님·낸ㅣ님에게 대상·약속·증거·콘티·CTA를 함께 보여줄 검토 초안을 만든다. 승인 권한을 임의 배정하지 않고 의견과 결정 담당자의 판단을 구분한다.
4. **제작**: 댄에게 승인된 자체 영상과 필요한 스톡/생성 입력을 인계하고, 알렉스에게 사건·구도·편집·사운드·규격을 넘긴다. 자산마다 실제 제품 증거인지 설명용인지 기록한다.
5. **검수**: 기술 재생, 실제 시청·청취, 제품 이해/카피, 권리, 요청된 사람 검토를 별도로 기록한다. 출력 버전이 바뀌면 이전 승인이 무엇을 커버하는지 다시 확인한다.
6. **학습**: 실제 게시했을 때만 URL·게시 시각·UTM을 붙이고, 약속한 시점에 같은 조건의 근거를 읽어 유지/수정/중단을 정한다. 지표가 없어도 인터뷰와 제품 이해도에 근거한 다음 검토는 가능하다.

## 기록 검사

```sh
python3 skills/gtm-cycle-review/scripts/review_cycle.py skills/gtm-cycle-review/assets/cycle.example.json --now 2026-10-24T09:00:00+09:00
```

검사기는 오직 기록의 신선도, 누락, 버전별 검토 상태를 계산한다. 관찰의 진위·광고 효과·영상 품질을 판정하거나 게시 권한을 부여하지 않는다. `review_packet_complete`도 사람이 자료를 볼 준비가 됐다는 뜻이다. 실제 실행에서는 현재 시각을 사용하고 시뮬레이션 시각을 실측으로 보고하지 않는다. 형식 오류는 종료 코드 2, 유효하지만 자료가 부족한 기록은 정상 결과에 누락 목록으로 표시한다.

출력은 `결과 / 관찰과 출처 / 다음 콘텐츠 가설 / 담당자별 인계 / 미결 검토 / 다음 시점`으로 짧게 정리한다. 사용자에게 다시 설명을 요구하기 전에 기록으로 채울 수 있는 부분을 채운다.
