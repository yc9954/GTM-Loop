# Soban Tales 편집 음향 검수와 납품

## 음악과 효과음

연속된 한 공연/광고 안에서는 전역 시간과 beat/bar 기준을 유지한다. 장면마다 음악 위상을 초기화하거나 거의 무음인 gate로 연결부를 자르지 않는다. 잡기·붓기 시작/정지·착지·부채·인사 Foley는 실제 사건 프레임에 별도 트랙으로 맞춘다.

종지 도착, 화면 reveal 시작, 완전 노출, release tail을 각각 기록한다. 타임스탬프 일치만으로 자연스럽다고 판단하지 말고 실제로 듣는다. 영상만 수정하며 음원을 보존하기로 했다면 불필요한 재인코딩을 피하고 추출 오디오 비트스트림 비교와 시청각 동기 확인을 구분한다. 컨테이너 파일 해시는 영상 변경만으로도 달라지므로 오디오 보존 증거가 아니다.

90분 식사의 수동 대기까지 음악 박자로 강제하지 않는다. 본 공연·대기·서빙·식사 루프는 전이 지점과 음향 페이드/종료 조건을 명시한다. 대기 루프 반복 때 사건·대사·농담이 재시작되지 않도록 한다. 메인의 최종 종지·등불은 마지막 그릇과 직원 손 철수를 확인한 수동 큐에 연결한다.

## 오류를 원인별로 고친다

| 관찰 | 먼저 분리할 원인 | Soban Tales 수정 방향 |
|---|---|---|
| 멈춤/툭 끊김 | 플레이어 버퍼, 인코딩 중복, 의도된 hold, 모션 경계 | 원본 타임라인과 디코딩 프레임 대조; 기다리는 연기를 무조건 제거하지 않음 |
| 손은 맞는데 몸이 끌림 | root/골반·발 접지, 그립 제약, 경로 속도 | 몸 전체 지지와 하중을 수정; 소품쪽으로 매 프레임 순간이동시키지 않음 |
| 기물·바닥 분리 | 부모/로컬 변환, 스케일, 접촉·레이어 시점 | 원 장면과 합성 가림 관계 수정; crop·빛으로 숨기지 않음 |
| 컷 경계에서 의상 튐 | 초기 상태·캐시·충돌·전 구간의 운동 | 앞 동작부터 평가하고 실제 렌더 비교 |
| 광고 확대가 흐림 | 작은 완성본 crop/중복 인코딩 | 원 장면에서 목표 출력으로 재렌더 |
| 음악이 재시작됨 | 구간별 박자 초기화·normalize·gate | 연속 음악과 분리 Foley, 자연스러운 tail |
| 투사 글자·웰컴 흔들림 | 프레임별 좌표·반올림·효과 | 정확한 고정 좌표 유지; 정지 지정 구간에만 프레임 동일성 검사 |
| 광고 CTA 가림 | 실제 placement UI·자막 영역 | 해당 채널 프리뷰로 점검; 과거 특정 광고의 하단 35%를 보편 수치로 복사하지 않음 |

## 서로 다른 검수 상태

각 항목에 pending/pass/fail/not_applicable와 근거를 남긴다. 관찰하지 않은 항목은 pending이다.

- 제품/서사: 최신 메뉴·인물/소품 ID·동작 원인·공개 문구.
- 공간/행동: 손·발·몸·기물·의상·가림·좌석 방향과 장면 경계.
- 프레임: 실제 출력 프레임의 실패 구간·투명도·깜박임·잘림.
- 기술: 파일 해시, 기대 규격 대비 길이·크기·FPS·프레임 수, codec/pixel format, audio 유무, 전체 decode. 평균 FPS만으로 CFR이라고 하지 않는다.
- 정상속도 시청: 해당 파일과 구간을 실제 재생했을 때만 통과.
- 청취/동기: 실제 음향 재생으로 박자·Foley·종지·소리 크기 관계를 확인했을 때만 통과.
- 현장: 실제 테이블·네 좌석·주변광·식기·서빙·지연·재시작·안전 화면의 리허설.

파일이 열리거나 contact sheet가 좋다는 이유로 정상속도 시청·청취·현장을 승인하지 않는다. 일부 정지 구간 검사 결과를 움직여야 하는 전체 공연에 적용하지 않는다.

## 편집 가능한 납품

실제 사용한 .blend, 텍스처/라이브러리/외부 캐시, 합성 소스, 렌더 설정, 분리 음향, 큐시트, 자산 ID/권리 기록과 파일 해시를 연결한다. .blend 한 파일이나 Pack Resources만으로 모든 캐시가 전달됐다고 가정하지 말고 새 위치에서 의존성과 대표 프레임을 확인한다. 존재하지 않는 .aep·리그·캐시를 납품 목록에 넣지 않는다.

run manifest에는 기준본, 변경/보존 구간, 출력 목적, FPS/캔버스, 자산/도구 버전, 출력과 검수 근거를 남긴다. video 스킬의 `assets/soban-run-manifest.json`은 빈 양식이며 승인된 작업 결과가 아니다. 현재 프로젝트 run 폴더에 복사해 채우고, 스킬 원본 폴더를 렌더 결과 저장소로 쓰지 않는다.

## 참고 자료에서 가져오지 않은 것

FORESIGHT 상시 무료 문구·출시 날짜·브랜드 로고·실적·과거 크레딧·게시 선호·옛 절대 경로·영상 길이/FPS는 Soban Tales의 요구사항이 아니다. 원 ZIP의 미디어 목록과 과거 검수 진술은 원 프로젝트 조사 기록이며 이번 작업의 직접 관찰이나 Soban Tales 증거가 아니다. 첨부 media_check.py는 검토만 했으며 복사·실행하지 않았다.
