# GTM Loop 운영 기준

2026-10-24 사용자 정의: GA에서 국가·콘텐츠·시각 반응을 읽고, Meta 광고 라이브러리에서 좋은 콘텐츠를 수집하고, 인터넷에서 비슷한 무료 콘텐츠를 찾아 Pexels·Higgsfield·Genjutsu 등으로 재제작한 뒤 다시 측정한다. 현재 프로젝트는 Soban Tales다. 이 문서는 운영 설계이며 자동 실행 엔진의 구현 보고가 아니다.

## 제작 정체성

무료 소스에서 시선을 잡는 훅을 찾고, Higgsfield를 중심으로 빠르고 쉽게 높은 퀄리티의 우리 콘텐츠로 재제작하는 것을 지향한다. Pexels·웹 소스는 출발점, 광고 레퍼런스는 표현 원리, GA는 다음 제작 가설의 근거다. 소스의 이용 조건과 생성 비용은 별도이며, 속도·품질을 측정된 보장 수치로 제시하지 않는다.

## 01 반응에서 다음 질문 찾기

입력: 실제 접근 가능한 GA 데이터, 비교 기간·국가·채널·콘텐츠 ID·UTM, 계측된 이벤트와 전환 정의.

국가별·콘텐츠별 반응을 같은 비교 조건에서 본다. 훅·색·구도·카메라·전환 등의 시각 태그를 콘텐츠/변형 ID에 연결한다. 측정되지 않은 시각 선호를 GA에서 직접 관찰했다고 쓰지 않는다. 유입량·노출 차이·표본·기간을 함께 기록하고 성과의 인과를 단정하지 않는다.

산출물: 데이터 출처와 기간, 관찰 사실, 불확실성, 다음에 바꿀 표현 한 가지와 성공 기준.

## 02 좋은 레퍼런스 수집

Meta 광고 라이브러리에서 해당 국가·언어·제품 맥락에 맞는 레퍼런스를 찾는다. 링크·광고주·확인일·훅·구도·편집 리듬·메시지·CTA와 무엇을 참고하는지 남긴다. 공개 목록의 존재나 장기 게재만으로 높은 전환율을 검증했다고 하지 않는다.

산출물: 레퍼런스 보드와 관찰 메모. 장면·음악·캐릭터를 복제하기보다 표현 원리를 가져온다. 기존 meta-ads CLI는 광고 계정 도구이며 공개 라이브러리 수집기로 간주하지 않는다.

## 03 비슷한 무료 소스 탐색

인터넷과 Pexels 등에서 장면 목적·촬영 시점·움직임·질감·비율에 맞는 후보를 찾는다. 무료 열람과 재사용 허가는 구분한다. 원본 링크·제작자·다운로드한 버전·이용 조건·인물/상표 관련 제한을 자산별로 기록한다. 찾지 못한 라이선스를 추정해 채우지 않는다.

산출물: 실제 사용 후보, 출처·조건, 우리 제품과 다른 점, 재제작할 요소.

## 04 재제작과 검토

제품 맥락과 실험 가설을 유지해 Pexels 소스 활용, Higgsfield 생성, Genjutsu 활용 또는 기존 로컬 제작 경로를 선택한다. 공식 도구명은 [Higgsfield Genjutsu](https://higgsfield.ai/genjutsu)다. 이 저장소에서는 해당 계정의 API·연결·생성 성공을 검증하지 않았다. 실제 사용 시 해당 도구의 접근 가능성과 지원 범위를 확인한다.

video-direction으로 콘티·구도·시선·전환을, video-shotcraft로 적합한 모션·편집을, video 가이드로 Blender/VFX·음향·납품을 연결한다. Soban Tales 투사 본편과 광고는 별도 산출물이며 고정 7:4 투사 좌표를 광고 카메라와 혼합하지 않는다.

산출물: 변형 ID, 원본/생성/편집 출처, 콘티, 편집 원본, 출력 규격, 검수 범위. 실제 사용하지 않은 도구를 제작 크레딧에 넣지 않는다.

## 재측정과 학습

공개/집행은 현재 요청 범위에 따라 진행한다. 배포했을 때만 실제 채널·링크·콘텐츠 ID·UTM·국가·기간·표현 태그를 남긴다. 다음 GA 분석에서 같은 기준으로 비교하고 유지/수정/폐기 결정을 기록한다. 광고 반응과 공연의 현장 품질 승인을 분리한다.

| 최소 기록 | 값 |
|---|---|
| loop_id / creative_id / variant_id | 실제 작업의 식별자 |
| 국가·언어·기간·목표 | 비교 조건과 계측 가능한 목표 |
| 가설·바꾼 표현·보존 요소 | 어떤 차이를 시험했는지 |
| GA 근거·레퍼런스·소스 | 출처 링크와 자산 조건 |
| 실제 제작 도구·출력·검수 | 사용한 것과 확인한 범위만 |
| 배포 링크·UTM·결과·다음 결정 | 실행 전에는 미정으로 유지 |
