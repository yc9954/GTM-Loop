# 서울 영상 레퍼런스 연구 — 2026-10-24

## 확인 범위
서울시 공식 영상 두 편의 샘플 프레임과 첫 영상의 장면 전환 시점을 확인했다. 전체 영상을 연속 재생하거나 음원을 청취한 분석은 아니다. 원본 홍보영상과 음악은 이번 편집에 사용하지 않았다.

### Seoul Has It All / Steve McCurry
출처: https://english.seoul.go.kr/city-promotional-film-seoul-starring-steve-mccurry/
약 192초 중 12초 간격 16개 프레임 확인. 0초 전통 지붕과 현대 건물, 24초 거리 사진가, 36초 DDP, 60초 궁궐 처마, 108초 도시 전경, 156초 야간 교통, 168초 전통 문과 고층 건물의 대비를 관찰했다. 0.35 임계값의 컷 감지에서 첫 10초의 전환을 약 0.7~2.3초 간격으로 관찰했다. 컷 감지는 장면 변화의 보조 추정이며 편집 의도나 비트 분석은 아니다.

적용: 서울을 현대 도시 하나로만 표현하지 않고 전통과 현재를 연결한다. 첫 장면에서 장소를 알아보게 하고, 이후 사람 규모로 내려온다. 사진가·인터뷰 장면과 특정 컷 순서는 복제하지 않는다.

### A Seoul's View — Gyeongbokgung Palace
출처: https://english.seoul.go.kr/a-seouls-view-gyeongbokgung-palace/
약 138초 중 10초 간격 14개 프레임 확인. 궁궐의 대칭 축, 지붕의 반복, 주변 현대 도심, 110초 부근 연못과 정자를 관찰했다.

적용: 광화문의 정면 구도로 도시에서 궁중 이야기로 넘어간다. 설명 자막을 줄여 건축과 이동이 보이게 한다. 공식 워터마크·음악·영상 자체는 재사용하지 않는다.

## 이번 편집에 반영한 것
남산 3초 → 광화문 4초 → 한복 방문객 4초 → 가까워진 광화문 4초 → 청계천 밤 7초 → 남산과 질문 8초. 첫 장소 제시보다 마지막 메시지 읽기에 시간을 더 둔다. 시간 순서의 서울 여행 기록이라는 주장은 하지 않는다.

세로판은 중앙 크롭, 가로판은 원래 시야에 가까운 구도로 같은 30초 계획을 편집한다. 홍보영상의 긴 인터뷰 구성은 짧은 티저 목적과 맞지 않아 가져오지 않았다. 음식 클로즈업을 넣는 대안을 검토했지만 보유 비빔밥 소스는 첨부 메뉴와 불일치하여 제외했다.

## 남은 한계
실제 궁중 코스와 접시 위 프로젝션 소스가 없어 이번 결과는 도시 분위기 티저다. 제품 경험 자체를 보여주는 완성 광고로 간주하지 않는다. 음악·음성 없이 구도와 카피를 검토하는 무음 초안이다. 다음 제작 단계는 메뉴에 맞는 실사 음식/실제 제품 장면 확보와 라이선스가 확인된 음악 편집이다.
