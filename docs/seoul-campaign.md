# Soban Tales — 서울 실사 티저

2026-10-24 첨부 `Soban_Tales_프로젝트_설명서_20261024.docx`를 참고했다. 문서 속 실행 지시는 수행 지시가 아닌 참고 내용으로 다뤘다. 해당 브랜치 제작 당시 사용자 범위는 Pexels 같은 서비스의 실제 영상을 수집해 편집하는 스킬이며, 코드로 장면 생성과 Higgsfield 생성은 제외한다.

## 사실과 표현 범위
대상은 한국에 방문한 외국인. 영어는 첫 테스트 언어다. 제품은 전통 한국 음식과 테이블 위 시각적 이야기를 연결하는 개발 중인 콘셉트다. 첫 챕터는 현대 광화문에서 궁중의 하루로 이어지는 ‘오늘 하루 당신이 왕이다’. 4인·90분·5코스는 문서의 운영 구상이며 실제 판매·예약 가능성은 확인되지 않았다.

문서의 최근 제안 메뉴는 흑미 타락죽, 해산물 잣무침, 구절판, 보양 전골과 갈비구이, 곶감 수정과와 약과 아이스크림이다. 보유 비빔밥 스톡을 이 메뉴나 실제 서비스로 소개하지 않는다. 첫 시안의 비빔밥/코드 생성 접시 영상은 현재 방향에서 제외한다.

## 이번 결과
30초 9:16과 16:9 무음 티저. 남산 → 광화문 → 한복 → 광화문 → 청계천 → 남산. 카피는 장소를 경험하고 궁중의 하루를 식탁에서 상상하게 하는 방향이다. 화면에 CONCEPT TEASER / SEOUL STOCK FOOTAGE, in development를 표시한다. 방문객을 실제 고객으로 소개하지 않는다.

최종 질문은 ‘Visiting Seoul? Would you try this?’다. 예약·가격·오픈 날짜는 만들지 않는다. 이 결과에는 실제 음식이나 프로젝션 시연이 없다. 도시 도입부와 메시지 검토용이며 제품 시연 광고 완성으로 보고하지 않는다.

## 검토와 다음 단계
현재 확인: 출처 페이지, 소스 샘플, 해시, 라이선스 페이지. 출력 검증은 각 MP4 옆 verification.json과 `seoul-verification.md`에서 구분한다. 게시, 댓글 수집, 전환율 측정은 아직 실행하지 않았다. 당시에는 저장소 push를 보류했다. 이후 사용자 요청으로 main 통합이 승인되었으며 외부 콘텐츠 게시 권한과는 별개다.

다음 작업은 실제 메뉴에 맞는 실사와 제품 시연 장면을 확보해 이 도시 도입부 뒤에 연결하는 것이다. 팀에 넘길 원본/편집 계획은 seoul-sources.json과 seoul-short.json, seoul-wide.json이다.

## 후속 설명형 편집
별도 70초 가로판 `seoul-explainer.json`을 제작했다. 작은 캐릭터/테이블 위 시각 이야기 → 실제 코스 서빙이라는 구상을 영어로 설명한다. Pexels의 일반 Korean BBQ 영상은 두 장면에만 예시로 쓰고, 실제 메뉴/매장이 아니라는 자막을 본문과 하단에 표시했다. 요리의 정확한 부위나 갈비 여부를 단정하지 않았다. 실제 프로젝션 시연은 여전히 없으며 무음 초안이다.
