# 준 작업 마무리 점검

## 원래 요청과 판정

이번 요청의 완료 단위는 **현황 조사, 기존 작업의 저장소 업로드, 필요한 스킬 선정과 프로젝트 특화**다. 실제 계정 연결·광고 집행·영상 납품·예약 실행은 별도 운영 단계다. 소스 구현과 실운영 검증을 합쳐 완료라고 보고하지 않는다.

## 마무리에서 찾은 결함과 수정

1. 전체 스킬 패키지가 video-shotcraft 원본 자료의 크기 때문에 30 MB 제한에서 실패했다. 원본·라이선스를 유지하면서 원본용 배포 검사에만 명시적으로 100 MB 제한을 적용한다. 웹 업로드 가능 용량을 보장하는 설정이 아니다.
2. 준의 세 스킬은 웹용 짧은 설명 매핑이 없어 웹용 묶음에서 제외됐다. 현재 진입 조건을 읽고 세 스킬의 설명 매핑을 추가했다. 아직 웹 클라이언트에 업로드·실행해 검증한 것은 아니다.
3. 근거/협업 검사 테스트는 로컬에서만 실행되고 있었다. 해당 스킬 또는 테스트가 바뀌면 CI에서 같은 검사를 실행하도록 연결했다.
4. 다른 작업 환경의 원격 이름을 쓴 실행 예시를 일반 clone의 origin/main으로 정정했다. 배포 안내의 다운로드 링크도 이 프로젝트 저장소를 가리킨다.

변경 시점의 검증 결과와 실제 원격 검사 상태는 해당 수정 PR에 남긴다. 전체 원본 패키징, 웹용 매핑 패키징, 압축 무결성, 저장소 밖에서 추출한 검사기 실행을 확인한다. 실제 계정이나 고객 자료를 테스트용으로 꾸미지 않는다.

## 첫 실사용에 필요한 최소 입력

사이트/GA 속성과 읽기 접근 또는 내보내기 자료, 목표 행동, 광고 플랫폼·캠페인의 읽기 자료, 고객 반응 보관 위치, 공개 가능한 자체 영상과 선택 구간이 필요하다. 협업자의 구체적인 역할과 해당 회차의 결정 담당자는 실제 협의 내용으로 채운다. 키·고객 원문·미공개 영상을 공개 저장소에 넣지 않는다.

이 입력이 들어오면 **한 콘텐츠·한 가설·한 비교 기간**으로 첫 회차를 실행한다. 아직 데이터를 모으지 못했으면 빈 기록의 누락 상태를 유지한다. “코드를 만들었다”, “패키지가 배포된다”, “마케팅 루프를 실운영했다”는 서로 다른 완료 상태다.
